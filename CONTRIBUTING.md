# Contributing to Physical-RSI

Thank you for helping keep the map accurate. Small, well-supported corrections are as valuable as
new entries.

## Pull requests

- Edit `data/reading-list.json`; do not hand-edit the generated section in `README.md`.
- Keep one work per entry and use a canonical, public link.
- Explain the category and tags in the pull request description when they are not obvious.
- Run `make check` and `make test` before opening the pull request.
- Keep unrelated formatting or dependency changes out of the same pull request.

For a larger taxonomy or scope change, open an issue first so that the structure can be discussed
before the list is rewritten.

## Style

Write notes in plain, specific language. Prefer "reports success on five simulated tasks" to
"achieves impressive generalization." A reader should be able to tell what was done, where it was
evaluated, and why it belongs in Physical-RSI.

By contributing, you agree that your additions can be distributed under this repository's MIT
License and that cited works remain the property of their respective authors.
